导出#

Exporting

警告

Warning

OpenUSD 支持目前仍处于实验阶段，可能会频繁变动。

OpenUSD support is currently experimental and subject to frequent change.

目前，将 MuJoCo 场景导出为 OpenUSD 格式是一个正在积极开发的领域。预计主要的导出方式是通过 Python API。

Currently, exporting MuJoCo scenes to OpenUSD format is an area of active development. The primary method for exporting is expected to be through the Python API.

原生 C++ 导出器（mujoco-usd）#

Native C++ exporter (mujoco-usd)

在 Linux x86_64、Windows x86_64 和 macOS arm64 上的 Python 3.11--3.13 中，安装 mujoco-usd （pip install mujoco-usd 或 pip install mujoco[usd]）后，即可通过 mujoco.usd.writer 和 mujoco.usd.layer_sink 进行原生 C++ OpenUSD stage 编写与轨迹记录，其底层由 mjcPhysics schema 支持。

In Python 3.11–3.13 on Linux x86_64, Windows x86_64, and macOS arm64, installing mujoco-usd (pip install mujoco-usd or pip install mujoco[usd]) provides native C++ OpenUSD stage authoring and trajectory recording via mujoco.usd.writer and mujoco.usd.layer_sink, backed by the mjcPhysics schemas.

USDExporter#

MuJoCo 还在 Python 中提供了纯 Python 实现的 USDExporter（仅需要 usd-core 和 pillow），可在所有平台和 Python 版本上导出场景和轨迹。

MuJoCo also includes the pure-Python USDExporter in Python (requiring only usd-core and pillow) for exporting scenes and trajectories across all platforms and Python versions.

mujoco-usd-converter#

若要按照严格的编写规范将现有 MJCF 资产转换为 USD，我们推荐使用 Newton mujoco-usd-converter。这些资产不会引用原始的 MJCF 资产，而是使用 mjcPhysics schema 来忠实地表示源资产。

To convert existing MJCF assets to USD following strong authoring guidelines we recommend the Newton mujoco-usd-converter. These assets will have no reference to the original MJCF assets but will use the mjcPhysics schemas to enable faithful representation of the source assets.

打开时，这些资产应与 MJCF 文件格式插件 生成的资产相似，但不会有将 MJCF 转换为 USD 所带来的任何运行时开销。

When opened, these assets should be similar to the ones generated by the MJCF file format plugin, but there will not be any runtime overhead from converting MJCF to USD.
