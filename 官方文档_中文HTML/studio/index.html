MuJoCo Studio#

备注

本页由 AI（Claude Sonnet）根据 MuJoCo 官方英文文档（2026-11-16 版）翻译，仅供学习参考；如有出入，以英文原版为准。术语对照见资料包中的 术语表.md 。

MuJoCo Studio 是一个 Python 和 C++ SDK，用于构建交互式仿真、研究工具和自定义可视化工具（visualizer），无需修改用户代码即可在原生桌面窗口或网页浏览器中运行。它是 simulate 应用程序和 mujoco.viewer 的下一代版本，用 Filament 基于物理的渲染（rendering）、Dear ImGui 即时模式 UI 和模块化的插件（plugin）系统，取代了经典的 OpenGL 渲染器和固定的 mjUI 面板。

MuJoCo Studio is a Python and C++ SDK for building interactive simulations, research tools, and custom visualizers that run in a native desktop window or in a web browser with no changes to user code. It is the next iteration of the simulate application and mujoco.viewer, replacing the classic OpenGL renderer and fixed mjUI panels with Filament physically based rendering, Dear ImGui immediate-mode UI, and a modular plugin system.

快速入门#

Quick Start

  • 在浏览器中（无需安装）：打开 live.mujoco.org，将任意 .xml、.mjb 或 .mjz 模型（model）拖放到画布上，或通过 ?model=github:<org>/<repo>/<branch>/<path> 分享模型 URL（参见 MuJoCo Live）。

    In the browser (zero install): Open live.mujoco.org and drag-and-drop any .xml, .mjb, or .mjz model onto the canvas, or share a model URL via ?model=github:<org>/<repo>/<branch>/<path> (see MuJoCo Live).

  • 独立桌面应用：下载最新版本，在 macOS 上打开 MuJoCoStudio.app，在 Windows 上打开 bin\mujoco_studio.exe，在 Linux 上打开 bin/mujoco_studio（参见独立应用程序）。

    Standalone desktop app: Download the latest release and open MuJoCoStudio.app on macOS, bin\mujoco_studio.exe on Windows, or bin/mujoco_studio on Linux (see Standalone Application).

  • 通过 Python CLI：在原生窗口中启动 Studio 查看器，或将其以无界面方式流式传输到浏览器：

    From the Python CLI: Launch the Studio viewer in a native window or stream it headlessly to a browser:
    python -m mujoco.studio.viewer --model=humanoid.xml            # native desktop window
python -m mujoco.studio.viewer --model=humanoid.xml --gfx=web  # headless web viewer

  • 在 Python 仿真循环内部：附加一个非阻塞查看器（launch_native.launch 或 launch_web.launch），而无需锁定 model 或 data；请参见 custom_sim_loop.py 和非阻塞模式。

    Inside a Python simulation loop: Attach a non-blocking viewer (launch_native.launch or launch_web.launch) without locking model or data; see custom_sim_loop.py and Non-Blocking Mode.

核心组件#

Core Components

MuJoCo Studio 围绕五个构建模块组织而成，这些模块在 C++ 和 Python 之间共享：

MuJoCo Studio is organized around five building blocks shared across C++ and Python:

  • Studio 查看器应用：功能完整的交互式可视化工具，在 C++ 中实现为 mujoco::studio::App （app.h），在 Python 中实现为 studio_app.App（app/plugins.py）。它提供模型加载、仿真历史回放、步进控制、性能剖析、集成的日志和警告控制台以及场景层次结构检查功能。

    Studio Viewer Application: The full-featured interactive visualizer, implemented as mujoco::studio::App (app.h) in C++ and studio_app.App (app/plugins.py) in Python. It provides model loading, simulation history scrubbing, step controls, performance profiling, an integrated log and warning console, and scene hierarchy inspection.

  • 可组合的插件：用于扩展查看器 UI、3D 场景和物理步进的模块化组件。在 Python 中，标准的 Studio UI（studio_app.App）、实时物理步进（StepControl）和轨迹历史记录（SimHistory）本身就是作为 ViewerPlugin 和 SimPlugin 的子类实现的，它们通过非阻塞的消息通道通信。

    Composable Plugins: Modular components that extend the viewer UI, 3D scene, and physics stepping. In Python, the standard Studio UI (studio_app.App), real-time physics stepping (StepControl), and trajectory history recording (SimHistory) are themselves implemented as ViewerPlugin and SimPlugin subclasses communicating over non-blocking message channels.

  • 即时模式 UI：由 Dear ImGui 驱动，即时模式 GUI（IMGUI）范式最大限度地减少了多余的状态复制、状态同步和 UI 侧的状态保留——使其比传统的保留模式界面更不易出错，非常适合快速迭代那些直接反映实时仿真数据的动态可视化和调试工具。控件调用并不直接操作 GPU 状态，而是输出紧凑的顶点缓冲区和绘制命令列表，这些内容可以在本地渲染，也可以远程流式传输（参见 WebViewer）。

    Immediate-mode UI: Powered by Dear ImGui, the immediate-mode GUI (IMGUI) paradigm minimizes superfluous state duplication, state synchronization, and UI-side state retention—making it less error-prone than traditional retained-mode interfaces and well suited for fast iteration on dynamic visualization and debugging tools that directly reflect live simulation data. Rather than touching GPU state directly, widget calls output compact vertex buffers and draw command lists that can be rendered locally or streamed remotely (see WebViewer).

  • 在浏览器中运行：Studio 提供两种网页查看器：MuJoCo Live 完全在浏览器中运行，可以托管在静态页面上；而 WebViewer 则将由主机驱动的 Python 仿真和 UI 流式传输到浏览器，主机上无需 GPU 或显示服务器。

    Running in the Browser: Studio offers two web viewers: MuJoCo Live runs entirely in the browser and can be hosted on a static page, whereas WebViewer streams a host-driven Python simulation and UI to the browser with no GPU or display server required on the host.

  • 基于物理的渲染：通过 Filament 在 OpenGL、Vulkan 和 WebGL 上实现硬件加速的基于物理的渲染（PBR），并提供用于自动化测试的无界面和软件光栅化器。有关 Filament 和基于物理的渲染理论的背景知识，请参见 Filament 文档、在线指南 Physically Based Rendering in Filament 以及 Physically Based Rendering: From Theory to Implementation。

    Physically Based Rendering: Hardware-accelerated physically based rendering (PBR) via Filament across OpenGL, Vulkan, and WebGL, plus headless and software rasterizers for automated testing. For background on Filament and physically based rendering theory, see the Filament documentation, the online Physically Based Rendering in Filament guide, and Physically Based Rendering: From Theory to Implementation.
