什么是 SdfFileFormat 插件？
--------------------------------

在 OpenUSD 框架中，\ ``Sdf`` 代表 Scene Description Foundations（场景描述基础层），它是负责场景数据序列化与组合的底层。
``SdfFileFormat`` 插件（plugin）是一种组件，用于让 USD 学会读取和写入某种特定的文件格式。

默认情况下，USD 自带针对其自有格式（``.usda``、\ ``.usdc``、\ ``.usdz``）的插件，社区也已创建了若干插件扩展，例如
`Adobe 文件格式插件
<https://github.com/adobe/USD-Fileformat-plugins/tree/main>`__。

MJCF ``SdfFileFormat`` 插件使支持 USD 的应用程序能够直接理解并操作 MuJoCo 原生的 ``.xml`` （MJCF）文件，就如同它们是原生 USD 文件一样。

它能实现什么？
------------------------

该插件可实现：

1.  **在 USD 中引用 MJCF 文件：** 使用标准的 USD 组合弧（如 reference、payload）将 MJCF 文件直接包含到更大的 USD 场景中。例如，可以把以 ``.xml``
    文件定义的 MuJoCo 机器人放入用 USD 建模的房间场景中。
2.  **在 USD 工具中加载 MJCF 文件：** ``usdview`` 等工具或其他基于 USD 的应用程序可以打开、检查并渲染（rendering）MJCF 文件，并即时将 MJCF 元素转换为 USD prim 和属性。
3.  **将 MJCF 转换为 USD：** 该插件可作为基础，用于将 MJCF 文件转换为持久化的 USD 文件（例如 ``.usda`` 或 ``.usdc``）。

本质上，它使 MJCF 成为 USD 生态系统中的一等公民。

用法
------------------

1.  **安装：** 参见 :doc:`building`。

2.  **在 USD 文件（例如 .usda）中引用：**

    .. code-block:: usd
        :caption: example.usda

        #usda 1.0
        (
            upAxis = "Z"
        )

        def Xform "world"
        {
            def "robot" (
                prepend references = @./my_robot.xml@
            )
            {
            }
        }

    在此示例中，\ ``my_robot.xml`` 是位于同一目录下的 MJCF 文件。USD 将使用该插件加载并解析其内容。

3.  **在 usdview 中打开：**

    .. code-block:: bash

       usdview my_robot.xml

    如果插件已正确设置，\ ``usdview`` 将渲染 MJCF 文件中定义的机器人。

4.  **在 Python 中使用（通过 USD API）：**

    .. code-block:: python

        from pxr import Usd

        # Load an MJCF file as a USD stage
        stage = Usd.Stage.Open('my_robot.xml')

        if stage:
            print(f"Successfully opened {stage.GetRootLayer().identifier}")
            # You can now inspect the stage as any other USD stage
            for prim in stage.TraverseAll():
                print(prim.GetPath())
        else:
            print("Failed to open MJCF file")

    该插件显著增强了 MuJoCo 与基于 USD 的工作流之间的互操作性，使 MJCF 中定义的物理资产能够无缝集成到更广泛的 3D 环境中。
