MuJoCo Live 离线版

来源：https://live.mujoco.org （MuJoCo Studio 的 WebAssembly 版，提交 4ed093a，2026-11-18 下载）
许可：Apache License 2.0（与 MuJoCo 相同，见 ..\官方仓库_模型与教程\LICENSE）

用法：
  1. 双击资料包根目录的“启动官方文档.bat”（需要 Python）；
  2. 在打开的首页点“MuJoCo Live · 浏览器仿真”。
  直接双击本目录的 index.html 打不开：浏览器在 file:// 下不允许加载 WebAssembly。

打开其他模型：
  地址栏写 index.html?model=<相对本页的路径>，例如
  http://localhost:8765/MuJoCo_Live/index.html?model=../官方仓库_模型与教程/model/car/car.xml
  也可以把 .xml（单文件）或打包好的 .zip / .mjz 模型直接拖进页面。

相对官方版的改动（只改了 live.js 和 index.html）：
  - 默认模型从 GitHub 上的 welcome.xml 改为 ../G1实战/models/unitree_g1/scene.xml；
  - ?model= 支持相对路径（自动转成本机 http 地址）；
  - 去掉 Google Fonts 外链。
