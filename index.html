建议的上手顺序

  1. 读入门教程前 7 章装好环境，跑通第一个模型，搞清 MjModel / MjData / mj_step。
  2. 跟着 G1 实战动手从站立、挥手、抗推到运行行走策略，第 0–10 课加附录，每课都有能直接运行的脚本。
  3. 对照中文文档查细节遇到 XML 属性或函数，查“XML 参考”和“API 参考”。

其他资料

  • G1 实战课程以宇树 Unitree G1 人形机器人为案例，第 0–10 课加附录。课程脚本在 G1实战\code\，模型在 G1实战\models\；每课也有 Markdown 版。
