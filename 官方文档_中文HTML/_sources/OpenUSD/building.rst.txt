====

.. WARNING:: OpenUSD 支持目前仍处于实验阶段，可能会频繁变动。

.. tip::
   如果你在 Linux ``x86_64`` 、Windows ``x86_64`` 或 macOS ``arm64`` 上使用 Python 3.11--3.13，可以直接通过 ``pip install mujoco-usd``
   （或 ``pip install mujoco[usd]`` ）从 PyPI 安装预构建的 C++ OpenUSD 绑定，无需从源码构建 OpenUSD 或 MuJoCo。

MuJoCo 必须针对预先构建好的 USD 库进行构建。我们提供了一个用于构建 USD 的工具，你也可以使用自己的 USD 库。

以下说明假设你已将 MuJoCo 克隆到 ``~/mujoco`` ，并且在 ``~/mujoco/build`` 下有一个构建目录。

.. _usdBuildingUSD:

构建 USD
--------

如果你已有预构建的 USD 库，可以跳过本节。

MuJoCo 提供了一个 CMake 项目来简化 USD 的构建过程。它会下载并构建 USD，且只启用必要的功能。

.. code-block:: bash

   cd ~/mujoco
   cmake -Bcmake/third_party_deps/openusd/build cmake/third_party_deps/openusd
   cmake --build cmake/third_party_deps/openusd/build

如果你想自定义构建过程，可以使用 USD 的 ``build_usd.py`` 脚本。建议使用位于克隆的仓库目录之外的独立安装目录。

.. code-block:: bash

   git clone https://github.com/PixarAnimationStudios/OpenUSD
   python OpenUSD/build_scripts/build_usd.py /path/to/my_usd_install_dir

.. _usdEnablingUSD:

启用 USD
--------

如果 USD 是通过 third_party_deps/openusd CMake 项目构建的，可以使用 MUJOCO_WITH_USD 标志来启用 USD 支持。

.. code-block:: bash

   cd ~/mujoco
   cmake -Bbuild -S. -DMUJOCO_WITH_USD=True
   cmake --build build -j 64

否则，如果你使用的是预构建的 USD 库，还必须传入 pxr_DIR 标志。

.. code-block:: bash

   cd ~/mujoco
   cmake -Bbuild -S. -DMUJOCO_WITH_USD=True -Dpxr_DIR=/path/to/my_usd_install_dir
   cmake --build build -j 64


现在运行 :ref:`simulate.cc <saSimulate>` ，就可以拖放 USD 文件了。

.. code-block:: bash

   simulate
