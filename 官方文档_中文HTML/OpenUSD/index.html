简介#

Introduction

本章介绍 MuJoCo 对 OpenUSD 的支持。USD（Universal Scene Description，通用场景描述）是由 Pixar 开发的、用于描述 3D 场景的开源框架。MuJoCo 的集成使用户能够利用 USD 丰富的生态系统和工具链。

This chapter describes MuJoCo’s support for OpenUSD. USD (Universal Scene Description) is an open-source framework developed by Pixar for describing 3D scenes. MuJoCo’s integration allows users to leverage USD’s rich ecosystem and tooling.

什么是 OpenUSD？#

What is OpenUSD?

USD 是一个高性能、可扩展的系统，用于描述、组合、仿真和协作处理 3D 数据。USD 最初由 Pixar Animation Studios 开发，目前已广泛应用于视觉特效、动画、游戏和机器人等多个行业，以简化复杂的 3D 工作流程。它为不同的软件应用提供了一种交换 3D 场景信息的通用语言。

USD is a high-performance, extensible system for describing, composing, simulating, and collaborating on 3D data. Originally developed by Pixar Animation Studios, USD is now used across various industries, including visual effects, animation, gaming, and robotics, to streamline complex 3D workflows. It provides a common language for different software applications to exchange 3D scene information.

为什么我们关注 OpenUSD？#

Why do we care about OpenUSD?

将 USD 与 MuJoCo 集成有以下几方面的优势：

Integrating USD with MuJoCo offers several advantages:

  • 互操作性： 众多 3D 内容创作工具（例如 Houdini、Maya、Blender）都支持 USD。这使 MuJoCo 用户可以轻松导入在这些工具中创建的场景和资产。

    Interoperability: USD is supported by a wide range of 3D content creation tools (e.g., Houdini, Maya, Blender). This allows MuJoCo users to easily import scenes and assets created in these tools.

  • 丰富的场景描述： USD 提供了一种强大而灵活的方式来表示复杂场景，包括几何体、材质、光照和层级结构。

    Rich Scene Description: USD provides a powerful and flexible way to represent complex scenes, including geometry, materials, lighting, and hierarchies.

  • 协作： USD 的分层与组合特性支持强大而高效的非破坏性创作流程。

    Collaboration: USD’s layering and composition features enable powerful and efficient non-destructive authoring pipelines.

USD 支持概览#

USD support overview

  • 导入： 您可以通过 MJCF 加载 USD 资产（具体为 .usd、.usda、.usdc、.usdz 文件），也可以将其拖放到 simulate.cc 中。

    Import: You can load USD assets (specifically .usd, .usda, .usdc, .usdz files) into MuJoCo via MJCF or dragging and dropping into simulate.cc.

  • Schema： MuJoCo 主要使用标准的 UsdPhysics schema 来表示物理属性。

    Schemas: MuJoCo primarily uses the standard UsdPhysics schemas for representing physics properties.

  • 扩展： 提供自定义的 mjcPhysics schema，用于涵盖 UsdPhysics 中没有的 MuJoCo 特有功能。

    Extensions: Custom mjcPhysics schemas are provided to cover MuJoCo-specific features not available in UsdPhysics.

  • MJCF 文件格式插件： 文件格式插件 允许在任何原生 USD 应用中将 MJCF 文件视为 USD 图层。

    MJCF File Format Plugin: A File Format Plugin allows treating MJCF files as USD layers in any native USD application.

  • 导出： MuJoCo 场景可以导出为 USD。

    Export: MuJoCo scenes can be exported to USD.
