mjcPhysics#

备注

本页由 AI（Claude Sonnet）根据 MuJoCo 官方英文文档（2026-11-16 版）翻译，仅供学习参考；如有出入，以英文原版为准。术语对照见资料包中的 术语表.md 。

警告

Warning

OpenUSD 支持目前处于实验阶段，可能会频繁变动。

OpenUSD support is currently experimental and subject to frequent change.

mjcPhysics 模式（schema） 允许直接在 USD 文件中详细描述 MuJoCo 仿真环境。其目标并非取代 UsdPhysics，而是扩展现有概念，仅在必要时才创建新的类型。

The mjcPhysics schema allows for detailed specification of a MuJoCo simulation environment directly within a USD file. The aim is not to replace UsdPhysics, but to extend existing concepts and create new types only where is necessary.

该模式既可以按 无代码（codeless） 方式使用，也可以通过其 C++ 绑定来构建。我们已通过 usdGenSchema 预先生成了供 MuJoCo 内部使用的 代码，不过它同样应当可以在 MuJoCo 之外使用。

The schema can be use codeless, or can be built with its C++ bindings. We’ve pre-generated the code via usdGenSchema for internal MuJoCo usage, but it should also work outside of MuJoCo.

API 模式#

API Schemas

MjcSceneAPI#

该 API 模式为 MuJoCo 仿真提供全局选项。它综合了 MJCF 中的 <option>、<option/flag> 和 <compiler> 元素。用户应将其应用到现有的 UsdPhysicsScene prim 上。

This API schema provides global options for the MuJoCo simulation. It is an amalgamation of the <option>, <option/flag> and <compiler> elements in MJCF. Users should apply this to an existing UsdPhysicsScene prim.

主要属性包括：

Key attributes include:

  • mjc:option：该命名空间下的属性映射到 <option> 元素。

    mjc:option: Attributes in this namespace map to the <option> element.

  • mjc:flag：该命名空间下的属性映射到 <option/flag> 元素。

    mjc:flag: Attributes in this namespace map to the <option/flag> element.

  • mjc:compiler：该命名空间下的属性映射到 <compiler> 元素。

    mjc:compiler: Attributes in this namespace map to the <compiler> element.

MjcSiteAPI#

该 API 类用于定义 MuJoCo 的 site，可应用于 UsdGeomSphere、UsdGeomCapsule、UsdGeomCylinder 以及 UsdGeomCube。

This API class is used to define a MuJoCo site, it can be applied to UsdGeomSphere, UsdGeomCapsule, UsdGeomCylinder, and UsdGeomCube.

MjcImageableAPI#

该 API 类为 MuJoCo 中纯视觉的实体提供属性，用 MuJoCo 的说法，我们将其量化为 contype = conaffinity = 0。

This API class provides attributes for strictly visual entities in MuJoCo, in MuJoCo terms we would quantify these has having contype = conaffinity = 0.

MjcCollisionAPI#

该 API 类应用于表示碰撞几何体的 prim，并且应与 UsdPhysicsCollisionAPI 一同应用。

This API class is applied to prims that represent collision geometry and should be applied alongside UsdPhysicsCollisionAPI.

MjcMeshCollisionAPI#

该 API 类应用于表示网格（mesh）碰撞几何体的 prim，并且应与 UsdPhysicsMeshCollisionAPI 一同应用。

This API class is applied to prims that represent mesh collision geometry and should be applied alongside UsdPhysicsMeshCollisionAPI.

MjcJointAPI#

该 API 类应用于 UsdPhysicsJoint prim，添加额外的属性以完整描述 MuJoCo 关节（joint）。

This API class is applied to UsdPhysicsJoint prims, adding extra attributes to fully describe MuJoCo joints.

MjcMaterialAPI#

该 API 类为物理材质提供属性，是对 UsdPhysicsMaterialAPI 的扩展。

This API class provides attributes for physical materials and is an extension of UsdPhysicsMaterialAPI

类型模式#

Type Schemas

MjcActuator#

该类表示 MuJoCo 的执行器（actuator），负责对通过 关系（relationship） 指定的传动（transmission）目标关节、刚体（body）或 site 施加力。

This class represents a MuJoCo actuator, which is responsible for applying force to a transmission target joint, body, or site specific via a relationship.

我们不使用现有的 UsdPhysicsDriveAPI，因为它更接近运行时的构造，其概念与此并不十分对应。

We do not use the existing UsdPhysicsDriveAPI as it is closer to a runtime construct and the concepts do not map very closely.

MjcKeyframe#

该类型保存张量值，用以表示特定时间点的仿真器状态。

This type holds tensor values representing simulator state at specific time values.

在 MJCF 中它是 <keyframe> 元素，并带有 time 属性。在 USD 中，我们改为将 time 属性映射到 timeSamples。

In MJCF this is the <keyframe> element and has a time attribute. In USD we map the time attribute to timeSamples instead.

关键帧（keyframe）中各值的顺序应与组合后的 stage 中刚体（rigidbody）的深度优先遍历顺序相对应。

The order of the values in the keyframes should map to the depth first ordered traversal of rigidbodies in the composed stage.

MjcTendon#

该类型同时表示固定肌腱和空间肌腱（tendon）。

This type represents both fixed and spatial tendons.

在 MJCF 中它是 <tendon> 元素。肌腱路径由 mjc:path 关系属性中的有序目标列表表示。在 MJCF 中，我们可以在路径目标上指定 sidesite 和 divisor 等属性；但在 USD 中，我们无法同样优雅地把数据附加到关系属性上，因此这些属性变成了带索引的数组属性，例如 mjc:sideSites 和 mjs:path:divisors。

In MJCF this is the <tendon> element. The tendon path is represented by the ordered list of targets in the mjc:path relationship attribute. In MJCF we can specify attributes such as sidesite and divisor on path targets; but in USD we cannot attach data to relationship attributes as elegantly, so these become indexed array attributes such as mjc:sideSites and mjs:path:divisors.
